# Pocket Apps

Personal iPhone launcher (a PWA hosted on GitHub Pages). The user installs it once via
Safari → Share → Add to Home Screen. Every folder in `projects/` shows up as an app tile.
The user mostly writes in English or German. **Everything must be bilingual (German + English).**

## Adding a new app or game

1. Create `projects/<id>/` (`<id>` = lowercase letters, digits, dashes, e.g. `snake`).
2. Add `projects/<id>/index.html` as the entry point. Other files (JS, CSS, images, sounds)
   can go in the same folder. Use **relative paths only**.
3. Add `projects/<id>/project.json`:
   ```json
   {
     "name": { "en": "Snake", "de": "Schlange" },
     "description": { "en": "Short English description", "de": "Kurze deutsche Beschreibung" },
     "icon": "🐍",
     "color": "#2f8f5b",
     "added": "YYYY-MM-DD"
   }
   ```
   Optional: put an `icon.png` (square) in the folder to use it instead of the emoji.
4. Deploy: `npm run deploy -- "Add snake game"`. This pulls, validates, commits and pushes.
   The GitHub Action (`.github/workflows/pages.yml`) then builds `projects.json` and publishes.
   The phone picks it up on its next launch, about 1-2 minutes after deploying.

The user can also upload apps themselves from the **dashboard** (`admin.html`, the + button in
the launcher). Those uploads commit straight to GitHub, so **run `git pull` before starting work**
(deploy does this automatically).

Folders starting with `_` are ignored (use them for drafts).

## Rules for projects

- **Bilingual:** pick the language with
  `localStorage.getItem('pocket.lang') || (navigator.language.startsWith('de') ? 'de' : 'en')`.
  The launcher's DE/EN button sets `pocket.lang`. Keep all UI strings in one `{ en: {...}, de: {...} }` object.
- **Self-contained:** no CDN or external requests if at all possible, so apps work offline.
  If a library is needed, copy the file into the project folder.
- **Mobile first:** touch/pointer input, `touch-action: none` for games, `viewport-fit=cover`,
  respect `env(safe-area-inset-*)`, no hover-only interactions, works in portrait.
- **Launcher overlay:** apps run full-screen in an iframe. A small draggable home button sits
  in the top-left corner by default, so keep important controls out of there.
- **Storage:** prefix localStorage keys with the project id (e.g. `snake.best`). All apps share one origin.
- **Audio** may only start after a user tap (iOS rule).
- **No personal data** in this repo. It is public on GitHub.
- Each project must also work when opened directly, without the launcher.

## Commands

- `npm run build` regenerates `projects.json` and validates the project folders
- `npm run serve` runs a local test server at http://localhost:8080
- `npm run icons` regenerates the launcher icons
- `npm run deploy -- "message"` runs build, commit and push

## Structure

- `index.html`, `app.js`, `style.css`: the launcher UI (tiles, iframe player, DE/EN switch)
- `sw.js`: service worker. Network-first with a cache fallback, and precaches all project files for offline use
- `projects.json`: generated by `tools/build.mjs` (git-ignored, and built by the Action on deploy). Do not edit by hand
- `admin.html`, `admin.js`: upload dashboard. Writes to the repo via the GitHub API using a
  fine-grained token (Contents: read/write on this repo only) that is stored on the device
  encrypted with a PIN (AES-GCM + PBKDF2) and only held in memory while unlocked. Never store
  the token unencrypted. All apps share one origin and could read localStorage.
- Git commits use the GitHub noreply email (privacy). Don't change that.
